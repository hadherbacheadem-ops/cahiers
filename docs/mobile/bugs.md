# Bugs mobiles — Nuit 2

Une ligne par bug : symptôme, appareil / moteur où il a été vu, cause, correction, test de non-régression. Trouvés par `scripts/mobile-matrix.mjs` (matrice `docs/mobile/matrix/<étape>/`), `scripts/overflow.mjs` (quel élément dépasse), `scripts/parity.mjs`, les tests Playwright de `tests/mobile/` et le parcours enregistré.

| 1 | Page fiche plus large que l’écran (+130 px sur iPhone SE, +60 sur iPhone 14, +20 sur Pro Max) : tout le contenu se décale, la carte « Couverture » sort du cadre | iPhone SE / 14 / 14 Pro Max, WebKit | Dans `CoverageSection`, la rangée barre de progression + « Générer pour ces points » + « Détail » n’avait pas `flex-wrap` ; les boutons en `whitespace-nowrap` poussaient la page | `flex-wrap min-w-0` sur la rangée ; `Button` passe en `max-w-full` et ne force `nowrap` qu’à partir de `sm` | matrice `fiche` 0 px ; `scripts/overflow.mjs fiche 320,390,430` |
